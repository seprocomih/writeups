# Repositorio de Writeups

¡Bienvenido a mi colección de writeups! En esta sección guardaré la documentación, guías paso a paso y resoluciones de retos que vaya completando.

## 📌 Objetivos del Proyecto
* Documentar de forma clara las soluciones de los retos.
* Mantener un registro ordenado de las metodologías utilizadas.
* Servir como material de consulta personal y para la comunidad.

## 📁 Estructura de Carpetas
Aquí te muestro cómo está organizado este repositorio:
1. `PINGUINO/` - Resoluciones de máquinas de las plataformas del Pinguino de Mario.
2. `WHHOAMI-LABS/` - Resoluciones de máquinas de la plataforma Whoami-Labs.
3. `HackTheBox/` - Resoluciones de máquinas de la plataforma HTB.
4. `TryHackMe/` - Guías detalladas sobre salas de THM.
5. `CTFs/` - Soluciones de eventos y competencias en vivo.

## 🛠️ Herramientas Utilizadas Comúnmente
* **Nmap** (Escaneo de puertos)
* **Burp Suite** (Análisis de tráfico web)
* **Gobuster** (Fuerza bruta de directorios)

> 💡 *Nota: Esta documentación se actualiza de manera constante a medida que completo nuevos retos.*
